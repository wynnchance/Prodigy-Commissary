Prodigy Commissary Redesign

Role-based redesign of the commissary admin software, built for jail staff first.

Working mockup

Pick a role and use it. Deposits post, fixes reverse, the drawer counts, the bank deposit builds, approvals apply, and the auditor's reports read what actually happened. Data lives in your browser; reset it from the footer any time.
Open the mockup

Detention Officer

Find or create an inmate, deposit cash, check, or card, bill for medical or damage, fix a mistake, print receipts.

  1. Deposit $20 cash for ALLEN, CHRISTOPHER WAYNE
  2. Fix it: move to the other Allen
  3. Bill a medical visit

Commissary Manager

Count the drawer, build the bank deposit, pay out releases, post carts, record the commissary transfer, reconcile the month.

  1. Count the drawer short by $5
  2. Mark the bank deposit
  3. Pay out GARZA, MARIA E

Jail Administrator

Approve what is waiting, set charge types and approval thresholds, manage staff and auditor logins.

  1. Approve the commissary transfer
  2. Turn on "deposits over $50 need approval"
  3. Deposit $60 as an officer and approve it

Auditor

Read-only report library and ledger. Every report is computed from the live data and every run is logged.

  1. Run Daily receipts to deposits
  2. Run Adjustments and fixes
  3. Build the audit packet

Prodigy Support and Accounting

All facilities, a facility page with "view as" into each jail's role views, the support queue, and the full ledger.

  1. Retry the Douglas JMS feed
  2. Connect Atoka's card processor, then deposit by card as an officer
  3. View Atoka as its Manager
The static screens from the first design pass are kept for reference. The design canvas and the roles plan live in the Claude project.
